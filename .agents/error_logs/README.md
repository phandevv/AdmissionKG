# Nhật ký Lỗi & Sự cố (Error Logs)

Thư mục này nằm trong `.agents/error_logs/`, dùng để lưu trữ toàn bộ các báo cáo lỗi và nhật ký sự cố phát sinh trong quá trình phát triển dự án **AdmissionKG**.

---

## 📌 Quy định Tạo & Quản lý File Lỗi:

1. **Tên file**: Sử dụng định dạng `YYYY-MM-DD.md` (Ví dụ: `2026-07-27.md`). Nếu trong cùng ngày xảy ra nhiều lỗi khác nhau, có thể ghi tên file: `YYYY-MM-DD_<ten_loi_ngan_gon>.md`.
2. **Định dạng chuẩn**: Sử dụng file mẫu [template.md](file:///c:/Users/bbqdd/Documents/_KhoaLuanTN/AdmissionKG/.agents/error_logs/template.md) để ghi nhận chi tiết.
3. **Lịch sử sửa lỗi (Fix Log)**: Bắt buộc ghi nhận rõ từng nấc sửa chữa (`Fix lần 1`, `Fix lần 2`, ...) cho tới khi lỗi được khắc phục dứt điểm.
