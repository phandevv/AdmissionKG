# React JS Frontend Development Skill

Kỹ năng này hướng dẫn các bước xây dựng giao diện React JS và trực quan hóa Knowledge Graph.

## 🛠 Hướng dẫn thực thi:
1. **Cytoscape.js Visualization**:
   - Sử dụng `CytoscapeComponent` từ `react-cytoscapejs`.
   - Cấu hình style cho các loại Nodes khác nhau (Trường, Ngành, Tổ hợp môn) với màu sắc rõ ràng.
2. **API Client**:
   - Khởi tạo instance Axios trong `services/apiService.js` với `baseURL: '/api'`.
