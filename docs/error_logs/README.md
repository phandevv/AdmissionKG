# Nhật ký Lỗi & Sự cố (Error Logs)

Thư mục này dùng để lưu trữ toàn bộ các báo cáo lỗi, sự cố phát sinh trong quá trình phát triển dự án **AdmissionKG**.

---

## 📌 Quy định tạo File Lỗi:

1. **Tên file**: Sử dụng định dạng `YYYY-MM-DD.md` (Ví dụ: `2026-07-27.md`). Nếu ngày đó có nhiều lỗi, có thể dùng `YYYY-MM-DD_ten_loi.md`.
2. **Định dạng**: Luôn sử dụng file mẫu [template.md](template.md) để ghi nhận chi tiết.
3. **Theo dõi tiến độ khắc phục**: Bắt buộc ghi nhận từng lần thử nghiệm sửa lỗi (`Fix lần 1`, `Fix lần 2`, ...) cho đến khi sự cố được khắc phục dứt điểm.

---
